# Guitar Pro tab to GuitarBot instructions script
This script converts Guitar Pro tabs (https://www.guitar-pro.com/) into executable instructions by the GuitarBot (https://github.com/MakinMusic247/GuitarBot)


## Troubleshooting
Note that PyGuitarPro python library only supports .gp3-5 file extensions. If using a later version you can export the tab in Guitar Pro (file --> export --> gp5...)
